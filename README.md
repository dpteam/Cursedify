# Cursedify

Однофайловый HTML5-инструмент для мемного искажения изображений, видео, GIF и
аудио. Проект использует тёмную OLED-тему с токсично-зелёным ретро-стилем и
рассчитан на работу локально в браузере.

## Статус

В разработке. Исходные референсы находятся в локальной папке `refs/` и не
отслеживаются Git.

## Направление разработки

- единый HTML-файл с CSS и JavaScript;
- импорт и экспорт медиа через браузерные API;
- эффекты разделены по типам медиа: изображения, видео, GIF и аудио;
- мемные эффекты: JPEG-crush, deep fry, low bitrate, glitch, pixelate,
  «ЖМЫХ», cooked, neon puke, thermal, ASCII dungeon, VHS, datamosh lite,
  калейдоскоп, echo chamber, bitcrush, telephone и другие;
- localStorage для настроек и автосохранения;
- responsive-интерфейс для desktop, touch и mobile.

## Сценарий для человека

1. Нажми **«ЗАГРУЗИТЬ ФАЙЛ»** или перетащи медиа.
2. Выбери тип медиа или нажми любой подходящий эффект.
3. Если это видео/аудио/GIF — используй Play, Stop и таймлайн.
4. Нажми большую зелёную кнопку **«Скачать результат»**.

Настройки эффекта запоминаются автоматически. Файл пользователя и исходник
никуда не отправляются.
