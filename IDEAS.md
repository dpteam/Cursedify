# Cursedify — карта идей и статуса

Этот файл — единый список фич, чтобы не потерять идеи между итерациями.

Обозначения:

- **DONE** — уже есть в текущем `index.html`.
- **PARTIAL** — работает частично или зависит от возможностей браузера.
- **TODO** — идея записана, но ещё не реализована.
- **REF** — идея требует проверки референсного скрипта или отдельного декодера.

## Ограничения текущей архитектуры

Приложение намеренно остаётся одним HTML-файлом. Поэтому оно использует только
браузерные API: Canvas, Web Audio, MediaRecorder и `captureStream`. Кодеки,
которые конкретный браузер не умеет декодировать, без WASM-бэкенда не появятся.
Это ограничение записано здесь специально, чтобы не принять его за случайный
баг при следующей итерации.
