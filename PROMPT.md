# Cursedify — техническое задание

## Проект и формат

- Название проекта: **Cursedify**.
- Приложение должно работать как один автономный файл `HTML5 + CSS + JavaScript`.
- Необходим локальный Git-репозиторий с именем автора **Meme Agent**.
- Исходный Python-скрипт хранится в `refs/`, а папка `refs/` игнорируется Git.
- Рабочие описания и планы находятся в `README.md` и `TODO.md`.

## Визуальный стиль

- Тёмная OLED-основа и токсично-тёмно-зелёные акценты.
- Атмосфера Facebook/VK 2008, мемный чёрный юмор и намеренно «проклятый» GUI.
- Для интерфейса использовать локальные SVG, Font Awesome-подобные иконки и emoji
  без обязательной внешней зависимости.
- Интерфейс должен оставаться понятным, быстрым и адаптивным.

## Медиа и эффекты

Приложение должно уметь загружать, просматривать, преобразовывать и экспортировать
изображения, видео, GIF и аудио с помощью доступных браузерных API.

Базовые мемные пресеты:

- **«ШАКАЛ»** — JPEG-crush с качеством около 0%;
- deep fry;
- низкий битрейт;
- мемный автотюн;
- глитчи;
- пикселизация;
- **«ЖМЫХ»**;
- cooked / «испечённое»;
- другие безопасные эффекты для забавного искажения медиа.

Разрешается портировать подходящие эффекты из предоставленного `.py`-скрипта.
Багованные или опасные режимы вроде `0x0` переносить нельзя.

## Технические требования

- `localStorage` и автосохранение/загрузка состояния;
- по возможности — HRTF и математические audio-эффекты;
- поддержка gamepad, touch и mobile;
- минимум кода при максимуме функциональности, в духе демосценовых алгоритмов;
- корректная обработка неподдерживаемых форматов и ошибок без падения приложения.
